## 2. Create the HARDCOVER in KDP

1. **kdp.amazon.com** → **Bookshelf** → **+ Create** → **Hardcover**.
2. Fill in **Hardcover Details** with the copy-paste blocks in section 3.
3. **Hardcover Content**: ISBN → **Get a free KDP ISBN**; Publication date → leave blank; Print options → **Black & white interior with white paper**, trim **6 × 9 in**, **No bleed**, cover finish **Matte**.
4. **Manuscript** → upload `interior-frostwood-16-the-quilts-of-frostwood.pdf`.
5. **Book cover** → **Upload a cover you already have** → upload `cover-frostwood-16-the-quilts-of-frostwood.pdf` (this is the **hardcover** wrap with hinge and wrap margin, not a paperback cover).
6. Answer the **AI-generated content** questions (section 4).
7. **Launch Previewer** → check every item in section 5 → **Approve** → **Save and Continue**.
8. **Hardcover Rights & Pricing**: Territories **All territories**; Primary marketplace **Amazon.com**; list price **$17.99** (60% royalty, about $3.99/copy).
9. Order a **proof copy** first if you can (section 5), then **Publish Your Hardcover Book**.

## Verification

All 100 puzzles (and the worked example): exactly one solution, found by both an independent SAT solver (CaDiCaL via python-sat, `src/sk_sat.py`) and an independent backtracking counter (`src/sk_bt.py`), and equal to the stored solution. Every puzzle is solvable by logic alone (the step-by-step solver in `src/shikaku.py` finishes with no guessing beyond the what-ifs its band allows) and fits its band: Easy needs exactly the T1 rules (a number with only one patch left, a square only one patch can reach); Medium and Hard need exactly T2 (+ squares only one number can reach, squares shared by all of a number's patches), Hard with bigger grids and more steps; Expert needs 1–3 what-ifs. A cross-check on copies with one number moved shows the two counters agree 100/100. Generation is deterministic (fixed seeds, `PYTHONHASHSEED=0`); a second run produced a byte-identical `data.json`. Full report: [verification.md](verification.md).
