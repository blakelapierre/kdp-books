## Verification
Every puzzle was checked by an independent SAT solver (CaDiCaL via python-sat, with lazily added connectivity cuts) and by an independent plain backtracking counter (`src/hashi_bt.py`, which shares no code with the generator). All 180 puzzles, plus the worked example, have exactly one solution, and it matches the stored answer. Each fits its band, graded by the generator's step-by-step logic solver: Easy (7×7, 10–14 islands) is solved by island counting alone; Medium (9×9, 16–22 islands) also needs the network rule; Hard (11×11, 22–30 islands) needs 1–3 one-step "what if?" deductions; Expert (13×15, 34–44 islands) needs 2–6. Generation is deterministic (fixed seeds; `PYTHONHASHSEED=0`), and a second run produced a byte-identical `data.json`. See [verification.md](verification.md).
