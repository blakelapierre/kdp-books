## 2. Create the Kindle ebook in KDP

1. **kdp.amazon.com** → **Bookshelf** → **+ Create** → **Kindle eBook**.
2. Fill in **Kindle eBook Details** with the copy-paste blocks in section 3.
3. **Kindle eBook Content**:
   - Manuscript → upload `standalone-03-tea-and-clues-at-tidewhistle-cove.epub` (the EPUB passed EPUBCheck 5.1.0 with 0 errors and 0 warnings). If KDP rejects it for any reason, upload the `.docx` instead.
   - Cover → **Upload a cover you already have** → upload `standalone-03-tea-and-clues-at-tidewhistle-cove-cover.jpg`
4. Answer the **AI-generated content** questions (section 4).
5. **Launch Previewer** (phone + tablet + Kindle) → check every item in section 5 → **Save and Continue**.
6. **Kindle eBook Pricing**: Territories **All territories**; Primary marketplace **Amazon.com**; royalty plan **70%**; list price **$3.99**. KDP Select is optional, but Google Play's free auto-narration only works if you **don't** enrol in KDP Select (see section 7).
7. Check that the delivery fee on screen is close to **$0.04**. Amazon measures its own converted file, so small differences are normal.
8. **Publish Your Kindle eBook**. This uses one of your two ebook slots for the week.

## 4. AI-generated content answers

KDP asks whether the book includes AI-generated content.

- **Text:** Yes. The stories and solutions were written with AI. The logic cases and fair-play clues were then checked by a program (see section 6). Pick the editing level that's true for you (it's "minimal or no editing" unless you edit it before publishing).
- **Images:** Yes. The cover was drawn by a code script written with AI, not by a generative image model. There are no images inside the book.
- **Translations:** No.

Answer honestly in the KDP form. The wording above matches how this book was made.

## 5. Preview checks

In the online Previewer (and on your phone after publishing):

- [ ] The Kindle **Go To → Contents** menu lists all 30 cases plus the front and back sections

- [ ] No pictures, tables or numbers in digits inside the cases
- [ ] Ends with *A Last Cup of Tea* (review request, no rewards offered) and *About the Author*

## 8. Rebuild

```bash
cd standalone/03-tea-and-clues-at-tidewhistle-cove/src
python3 verify.py   # logic brute force + fair-play + read-aloud/content checks -> ../verification.md
python3 cover.py    # -> ../standalone-03-tea-and-clues-at-tidewhistle-cove-cover.jpg
python3 build.py    # -> ../standalone-03-tea-and-clues-at-tidewhistle-cove.epub, ../standalone-03-tea-and-clues-at-tidewhistle-cove.docx, ../build-info.json
java -jar epubcheck.jar ../standalone-03-tea-and-clues-at-tidewhistle-cove.epub   # EPUBCheck 5.1.0: 0 errors, 0 warnings
```

The story text is in `src/cases_a.py`, `cases_b.py` and `cases_c.py`, and the front and back matter are in `src/book.py`. Verification results: [verification.md](verification.md). Listing draft and demand evidence: [listing.md](listing.md).
