# Standalone books

Books that are **not** part of a series go here, one folder per book, with the same layout as the series books (`src/`, `previews/`, `interior.pdf`, `cover.pdf`, `listing.md`, and a verification report).

A book belongs in `series/<name>/` if it shares a setting, a house style and a series line with other books. Otherwise it goes here. A book that is Christmas-specific, for example, doesn't fit the Frostwood series (winter, but not Christmas) even if it borrows the name.

## Books

Folders are numbered `NN-<book-slug>` in creation order; a new book gets the next number (see the [main README](../README.md#folder-numbering)).
