## 2. Create the Kindle ebook in KDP

1. **kdp.amazon.com** → **Bookshelf** → **+ Create** → **Kindle eBook**.
2. Fill in **Kindle eBook Details** with the copy-paste blocks in section 3.
3. **Kindle eBook Content**:
   - Manuscript → upload `standalone-13-twenty-four-nights-at-the-christmas-post.epub`. If KDP rejects it, upload the `.docx` instead.
   - Cover → **Upload a cover you already have** → upload `standalone-13-twenty-four-nights-at-the-christmas-post-cover.jpg`
4. Answer the **AI-generated content** questions (section 4).
5. **Launch Previewer** (phone + tablet + Kindle) → check every item in section 5 → **Save and Continue**.
6. **Kindle eBook Pricing**: Territories **All territories**; Primary marketplace **Amazon.com**; royalty plan **70%**; list price **$3.99**. Leave **KDP Select OFF** for Google Play auto-narration later (section 7).
7. Check that the delivery fee on screen is close to **$0.05**. Amazon measures its own converted file, so small differences are normal.
8. **Publish Your Kindle eBook**. This uses one of your ebook slots for the week.

## 7. Audio (Sunday routine)

- **Virtual Voice** (Audible, Amazon-only): once the ebook is live, look on your KDP Bookshelf for **"Add Audible audiobook with virtual voice"** (invite-only).
- **Google Play auto-narration**: only if the ebook is **not** in KDP Select. Keep Select **OFF**.
- Each *Think about it...* line is followed by "Take a moment to talk it over, or pause here if you are listening." Leave a two-to-three second gap there in narration.
- The snowflake letters are single spoken letters (for example "the letter V"); listeners may want a pencil.

## 8. Rebuild

```bash
cd standalone/13-twenty-four-nights-at-the-christmas-post/src
python3 verify.py   # clue placement, snowflake message, Secret Santa logic, audio-first/content checks -> ../verification.md
python3 cover.py    # -> ../standalone-13-twenty-four-nights-at-the-christmas-post-cover.jpg
python3 build.py    # -> ../standalone-13-twenty-four-nights-at-the-christmas-post.epub, .docx, ../build-info.json
# EPUBCheck: not run on this box (no Java). All EPUB XML files parse cleanly.
```

Night text is in `src/cases_a.py` (nights one to twelve) and `src/cases_b.py` (thirteen to twenty-four); front and back matter are in `src/book.py`. Verification: [verification.md](verification.md). Listing draft and demand evidence: [listing.md](listing.md).
