## 2. Create the Kindle ebook in KDP

1. **kdp.amazon.com** → **Bookshelf** → **+ Create** → **Kindle eBook**.
2. Fill in **Kindle eBook Details** with the copy-paste blocks in section 3.
3. **Kindle eBook Content**:
   - Manuscript → upload `standalone-07-three-clues-by-candlelight.epub`. If KDP rejects it, upload the `.docx` instead.
   - Cover → **Upload a cover you already have** → upload `standalone-07-three-clues-by-candlelight-cover.jpg`
4. Answer the **AI-generated content** questions (section 4).
5. **Launch Previewer** (phone + tablet + Kindle) → check every item in section 5 → **Save and Continue**.
6. **Kindle eBook Pricing**: Territories **All territories**; Primary marketplace **Amazon.com**; royalty plan **70%**; list price **$3.99**. Leave **KDP Select OFF** if you want Google Play free auto-narration later (see section 7).
7. Check that the delivery fee on screen is close to **$0.02**. Amazon measures its own converted file, so small differences are normal.
8. **Publish Your Kindle eBook**. This uses one of your two ebook slots for the week.

## 4. AI-generated content answers

KDP asks whether the book includes AI-generated content.

- **Text:** Yes. The riddles and framing were written with AI, then checked by a program for unique answers, structure, audio-first rules and non-violence (see section 6). Pick the editing level that's true for you.
- **Images:** Yes. The cover was drawn by a code script written with AI, not by a generative image model. There are no images inside the book.

## 5. Preview checks
