## 2. Create the Kindle ebook in KDP

1. **kdp.amazon.com** → **Bookshelf** → **+ Create** → **Kindle eBook**.
2. Fill in **Kindle eBook Details** with the copy-paste blocks in section 3.
3. **Kindle eBook Content**:
   - Manuscript → upload `standalone-15-clues-between-the-shelves.epub`. If KDP rejects it, upload the `.docx` instead.
   - Cover → **Upload a cover you already have** → upload `standalone-15-clues-between-the-shelves-cover.jpg`
4. Answer the **AI-generated content** questions (section 4).
5. **Launch Previewer** (phone + tablet + Kindle) → check every item in section 5 → **Save and Continue**.
6. **Kindle eBook Pricing**: Territories **All territories**; Primary marketplace **Amazon.com**; royalty plan **70%**; list price **$3.99**. Leave **KDP Select OFF** for Google Play auto-narration later (section 7).
7. Check that the delivery fee on screen is close to **$0.04**. Amazon measures its own converted file, so small differences are normal.
8. **Publish Your Kindle eBook**. This uses one of your ebook slots for the week.

## 4. AI-generated content answers

KDP asks whether the book includes AI-generated content.

- **Text:** Yes. The stories were written with AI, then checked by a program for structure, clue placement, four logic cases (unique solutions by enumeration), audio-first rules and non-violence (see [verification.md](verification.md)). Pick the editing level that's true for you.
- **Images:** Yes. The cover was drawn by a code script written with AI, not by a generative image model. There are no images inside the book.
- **Translations:** No.

## 7. Audio (Sunday routine)

- **Virtual Voice** (Audible, Amazon-only): once the ebook is live, look on your KDP Bookshelf for **"Add Audible audiobook with virtual voice"** (invite-only).
- **Google Play auto-narration**: only if the ebook is **not** in KDP Select. Keep Select **OFF**.
- Each *Think about it...* line is followed by "Take a moment, or pause here if you are listening." Leave a two-to-three second gap there in narration.

## 8. Rebuild

```bash
cd standalone/15-clues-between-the-shelves/src
python3 verify.py   # clue placement, four logic cases, audio-first/content checks -> ../verification.md
python3 cover.py    # -> ../standalone-15-clues-between-the-shelves-cover.jpg
python3 build.py    # -> ../standalone-15-clues-between-the-shelves.epub, .docx, ../build-info.json
# EPUBCheck: not run on this box (no Java). All EPUB XML files parse cleanly.
```

Case text is in `src/cases_a.py` (cases one to fourteen) and `src/cases_b.py` (fifteen to twenty-eight); front and back matter are in `src/book.py`. Verification: [verification.md](verification.md). Listing draft and demand evidence: [listing.md](listing.md).
