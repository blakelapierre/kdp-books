# Ideas log

This log lists every KDP book idea that has already been **built** or **evaluated**. Future daily idea scans should check it and skip anything listed here, or a close variant of it.

## User preferences
- **No killing or violent themes.** No murder mysteries, no violent crime, no gore. Cozy themes like theft or puzzle mysteries are fine.
- Author name: Blake La Pierre. Default price: $9.99, the lowest price that earns the 60% paperback royalty.

## Puzzle types already used in the Frostwood series
Elimination mystery (book 1), Train Tracks (book 2), Star Battle / Two Not Touch (book 3), Tents / Tents and Trees (book 4), cozy riddles + text logic for Kindle (book 5), nonograms / hanjie (book 6), Hashi / Bridges (book 7) and Slitherlink / Loop the Loop / Fences (book 8, hardcover). Every new Frostwood book should use a different type. See [series/frostwood/README.md](series/frostwood/README.md).

## Puzzle types used in standalone books
*Tea and Clues at Tidewhistle Cove* uses prose solve-it mini-mysteries (observation/alibi clues) plus seven text logic cases: only-the-thief-lies, exactly-one-truth, seating order, walking-time alibis, honest/fibber fishermen, queue order, one-truth-one-fib. A second seaside/tea-room mini-mystery book would be a sequel, not a new idea.

*Logic on Lantern Lane* is a full dedicated logic grid (Einstein / zebra) book: 40 cozy village scenes, each used in three levels, clue types positive, negative, comparison, exact gap, either-or, neither-nor and "of A and B, one … the other …". *The Advent Clock* used one logic grid door, which is fine. A second logic grid book would be a sequel (e.g. another village), not a new idea.

*Fireside Cryptograms* uses monoalphabetic substitution cryptograms (cryptoquotes) only — 200 puzzles with independent uniqueness verification.

*Tents in Frostwood* (Frostwood book 4) is a full dedicated Tents book; *The Advent Clock* used Tents only once as a single advent door, which is fine.

*The Advent Clock* uses one each of: word search (×2), Caesar cipher, pigpen cipher, Morse code, Star Battle-style "one star per row/column/region" (×2), wordoku (×2), maze, nonogram (×2), number pyramid, logic grid, Tents, Train Tracks (×2), Akari, fill-in, Minesweeper-style "presents", Futoshiki, Battleships-style "sleigh fleet", Skyscrapers and KenKen-style cages. A second Christmas/advent book would be a close variant. (Its two Star Battle-style doors overlap only slightly with Frostwood book 3, a full 180-puzzle Star Battle book.)

*The Frostwood Sketchbook* (Frostwood book 6) is a full dedicated nonogram book (pictures from the Noto Emoji typeface, one subject per puzzle). *The Advent Clock* used two nonogram doors, which is fine. Another nonogram book would be a sequel (e.g. a different theme or larger 8.5 × 11 grids).

*Bridges of Frostwood* (Frostwood book 7) is a full dedicated Hashi / Bridges (Hashiwokakero) book: 180 puzzles from 7×7 to 13×15, verified unique by SAT plus an independent backtracker. Another Hashi book would be a sequel (e.g. larger 8.5 × 11 maps), not a new idea.

*Porch Swing Crosswords* is a full dedicated crossword book: 80 freeform (criss-cross) themed crosswords, 20 per season (Spring and Summer Easy, Autumn and Winter Medium), plain clues, a word bank per puzzle, and no answer repeated in the book. *The Advent Clock*'s fill-in door is a different puzzle. Another themed crossword book would be a sequel (e.g. a different setting or Medium-to-Hard), not a new idea.

*Stories We Keep* is a guided memory keepsake journal (hardcover): eight life-story chapters with writing prompts, family tree, timeline, letter pages and extra lined pages — not a puzzle book. Another life-story journal aimed at a single role (Mom-only / Grandma-only) would be a sequel, not a new idea.
