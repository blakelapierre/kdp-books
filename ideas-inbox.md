# Ideas inbox

Paste research from main Grok Automations (grok.com/automations) here. The weekly standalone book build and the weekly Frostwood build read this file and pick an unused idea for the format slot that day.

## Conventions
- Newest research block at the **top** (below this header).
- Keep each pasted block intact, with the date and source (e.g. `## 2026-11-09 — main Grok weekly research`).
- When a build uses an idea, mark it in place: change the idea line to start with `USED YYYY-MM-DD — ` (and optionally note the folder), or add a one-line `> USED YYYY-MM-DD → path/to/book` under it. Do not delete the research.
- Do not invent ranks, review counts, or prices here; only paste what the automation reported from public pages.
